# Publicar no GitHub — woflymidas-rgb

1. Entre na sua conta pelo navegador. Não envie senha/token ao assistente.
2. Abra https://github.com/new . Owner: woflymidas-rgb; Repository name: ats-prancheta.
   Escolha Public. Não selecione README, licença ou .gitignore: a pasta já traz esses arquivos.
3. Clique Create repository e envie ao assistente a URL criada.
4. O código local pode ser enviado por Git/GitHub Desktop; não envie a pasta original de
   desenvolvimento, saves ou o ZIP de instalação como se fosse código-fonte.
5. Depois de conferir compilação, instalador e licenças dos recursos, crie uma Release
   v1.0.0, anexando instalador, ZIP portátil e SHA256SUMS. Use Save draft antes de publicar.
6. Nos fóruns, compartilhe a URL da release e a do repositório para auditoria.

Criar o repositório, subir o código e publicar a release são etapas diferentes.
